فعال‌سازی PHP روی Live Server ۲ دقیقه

از نسخهٔ ۱٫۷٫۵ فایل‌های PHP روی سرور داخلی اجرا می‌شوند — به php-cgi نیاز دارد:

1️⃣

بگیرید

PHP (نسخهٔ Thread Safe، فایل زیپ) را از windows.php.net/download بردارید — یا اگر XAMPP دارید، پوشهٔ C:\xampp\php از قبل php-cgi.exe دارد.

2️⃣

قرار دهید

پوشهٔ PHP را به PATH ویندوز اضافه کنید — یا ساده‌تر: کل پوشه را کنار rea-studio.exe کپی کنید (خودکار پیدا می‌شود).

3️⃣

ری‌استارت

Live Server را خاموش و روشن کنید. بج بالای همین صفحه سبز می‌شود و فرم تماس واقعاً ذخیره می‌کند.

تاریخچهٔ نسخه‌ها

خلاصهٔ تغییرات — جزئیات کامل در CHANGELOG هر نسخه داخل پوشهٔ دانلود.

1.7.5۲۰۲۶-۱۰-۳۱آخرین
  • 🐘 اجرای PHP: درخواست‌های ‎.php از طریق php-cgi (CGI/1.1) اجرا می‌شوند — POST، کوکی و QUERY_STRING کامل.
  • خواندن کامل بدنهٔ درخواست: قبلاً فقط ۴۰۹۶ بایت اول هر درخواست دیده می‌شد؛ الان Content-Length تا ۸ مگابایت خوانده می‌شود.
  • صفحهٔ راهنمای فارسی هنگام درخواست PHP وقتی php-cgi نصب نیست.
  • پایداری: timeout خواندن/نوشتن برای اتصال‌های نیمه‌کاره + پشتیبانی index.php به‌عنوان صفحهٔ پیش‌فرض.
1.7.4۲۰۲۶-۱۰-۳۱
  • امضای دیجیتال Authenticode (self-signed همراه با گواهی و راهنمای نصب) + مقاوم‌سازی قفل‌های lsp.rs در برابر deadlock.
1.7.3۲۰۲۶-۱۰-۳۱
  • حفاظت انکدینگ: صفحات windows-1252/1256 و UTF-16 در پیش‌نمایش زنده دیگر خراب نمی‌شوند (sniff + تزریق بایت‌سطح).
  • پرامپت اعتماد DAP: قبل از اجرای launch.json سه گزینهٔ Always / Once / Cancel.
1.7.2۲۰۲۶-۱۰-۳۱
  • رفع بحرانی‌ها: crash پنل ترمینال (focus split-borrow)، اجرای liveserver خارج از رشتهٔ UI، سقف بافر ۴MB، کدهای کنترل VT.
  • نصاب NSIS برای اولین بار.
⚠️ دربارهٔ هشدار SmartScreen: گواهی REA Studio از نوع self-signed است، بنابراین ویندوز اولین بار هشدار «Unknown Publisher» می‌دهد. برای حذف هشدار، فایل REAStudio-Certificate.cer را دانلود و نصب کنید (راهنمای ۵ مرحله‌ای داخل README-Certificate-FA.txt کنار فایل دانلودی).
