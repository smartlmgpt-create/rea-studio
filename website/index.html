ویرایشگر کدی که فقط ۶٫۵ مگابایت است — بدون Electron، بدون اکانت، بدون تله‌متری

REA Studio یک ویرایشگر کد بومی ویندوز است که با Rust و egui ساخته شده. ترمینال داخلی، سرور زندهٔ وب با ریلود خودکار، اجرای PHP و دیباگر — همهٔ این‌ها در یک فایل exe مستقل که در کمتر از یک ثانیه بالا می‌آید.

⬇️ دانلود رایگان مقایسه با Notepad++ و VS Code
main.rs — REA Studio 
// کل ادیتور در همین تابع شروع می‌شود 🚀
fn main() {
    let app = App::new("workspace/");
    app.open_terminal();      // ConPTY داخلی
    app.start_live_server(); // ریلود خودکار + PHP
    app.attach_debugger();   // DAP با پرامپت اعتماد

    egui::run(app, |ui| {
        ui.label("6.5 MB — صفر وابستگی خارجی");
    });
}

امکانات

هر قابلیت، بومی و سبک — بدون بارگذاری موتور مرورگر یا رانتایم جانبی.

🖥️

ترمینال داخلی واقعی

ConPTY ویندوز با پشتیبانی ANSI/VT، بافر هوشمند ۴ مگابایتی و اجرای مستقیم cargo، git و php.

⚡

Live Server با ریلود خودکار

هر فایلی را که ذخیره کنید مرورگر خودش رفرش می‌شود — HTML، CSS، JS، تصویر و فونت، همه زیر نظرند.

🐘

اجرای PHP جدید در ۱٫۷٫۵

فایل‌های .php از طریق php-cgi اجرا می‌شوند؛ POST، کوکی و متغیرهای CGI کامل پاس داده می‌شوند.

🐞

دیباگر DAP با پرامپت اعتماد

قبل از اجرای launch.json از شما پرسیده می‌شود؛ اجرای خودکار پیکربندی ناشناس ممنوع است.

🛡️

حفاظت انکدینگ صفحات

صفحات قدیمی windows-1256 و UTF-16 در پیش‌نمایش زنده خراب نمی‌شوند — ریلود بدون دست‌زدن به بایت‌ها.

✍️

امضای دیجیتال + نصاب

exe امضاشدهٔ Authenticode و نصاب NSIS؛ گواهی self-signed همراه بسته ارائه می‌شود.

💡 همین سایت، دموی زندهٔ همین قابلیت‌هاست! این صفحه الان روی Live Server خودِ REA Studio اجرا می‌شود. به بج «PHP» در بالای صفحه نگاه کنید: اگر سبز است یعنی php-cgi فعال است و فرم تماس واقعاً پیام‌ها را در php/data/messages.json ذخیره می‌کند؛ اگر قرمز است، سایت به‌صورت استاتیک کار می‌کند و فرم در حالت نمایشی (localStorage) عمل می‌کند — راهنمای فعال‌سازی PHP دو دقیقه بیشتر وقت نمی‌گیرد.
