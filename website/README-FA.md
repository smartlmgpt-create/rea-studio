# سایت نمونهٔ REA Studio — راهنمای اجرا

این سایت (HTML + CSS + JS + PHP) دقیقاً برای اجرا روی **Live Server داخلی REA Studio** ساخته شده
و نیازی به هیچ چیز دیگری ندارد (بدون CDN، بدون فونت وب، بدون Node).

## اجرا در REA Studio (بدون PHP — ۳۰ ثانیه)

1. پوشهٔ `rea-website` را در REA Studio باز کنید (File → Open Folder).
2. از نوار وضعیت پایین روی **○ Live Server** کلیک کنید (یا پنل Live را باز کنید و Start بزنید).
3. مرورگر را روی `http://127.0.0.1:5500` باز کنید.
4. هر فایلی را ذخیره کنید → مرورگر خودش ریلود می‌شود. ✅

در این حالت همهٔ صفحات، پوستهٔ روشن/تاریک و انیمیشن‌ها کار می‌کنند؛ فقط فرم تماس
در «حالت نمایشی» عمل می‌کند (پیام در localStorage مرورگر ذخیره می‌شود) و بج PHP قرمز است.

## فعال‌سازی PHP (۲ دقیقه)

1. **PHP** (نسخهٔ Thread Safe، فایل زیپ) را از `windows.php.net/download` بگیرید و یک‌جا Extract کنید —
   یا اگر XAMPP دارید، از پوشهٔ آمادهٔ `C:\xampp\php` استفاده کنید (خودش php-cgi.exe دارد).
2. پوشهٔ PHP را به **PATH ویندوز** اضافه کنید — یا ساده‌تر: کل پوشه را **کنار `rea-studio.exe`** کپی کنید
   (از نسخهٔ ۱٫۷٫۵ خودِ برنامه آنجا را هم جست‌وجو می‌کند).
3. در REA Studio، **Live Server را خاموش و دوباره روشن کنید**.

بج «PHP» در بالای سایت سبز می‌شود (نام نسخهٔ PHP را نشان می‌دهد) و از این پس:

- فرم تماس واقعاً POST می‌شود و پیام‌ها در `php/data/messages.json` ذخیره می‌شوند
  (این فایل را در پنل فایل‌های REA باز کنید و ببینید!).
- `php/health.php` و `php/version.php` دو API نمونه با خروجی JSON هستند
  (دومی با `?from=1.7.2` هم کار می‌کند — بررسی «آپدیت هست؟»).
- فایل‌های `index.php` هم اگر بسازید، به‌جای index.html سرو می‌شوند.

## ساختار پروژه

```
rea-website/
├── index.html        صفحهٔ اصلی (هیرو، امکانات، مقایسهٔ کوتاه)
├── compare.html      جدول کامل مقایسه با Notepad++ و VS Code
├── download.html     دانلود + تاریخچهٔ نسخه‌ها + راهنمای PHP
├── contact.html      فرم تماس (POST واقعی به PHP)
├── css/style.css     استایل کامل (بدون هیچ فایل بیرونی)
├── js/app.js         پوسته، ریلود-ریویل، وضعیت PHP، فرم
├── php/
│   ├── health.php    API وضعیت (JSON)
│   ├── version.php   API نسخهٔ آخر (JSON، با ?from=)
│   ├── contact.php   ذخیرهٔ پیام‌ها (اعتبارسنجی + honeypot)
│   └── data/         messages.json اینجا ساخته می‌شود
├── favicon.svg
└── README-FA.md      همین فایل
```

## نکته‌ها

- **ریلود خودکار:** صفحهٔ PHP هم بعد از تغییر فایل‌ها رفرش می‌شود (پروب ریلود روی خروجی PHP تزریق نمی‌شود؛
  تغییر فایل → رفرش صفحهٔ فعلی کافی است، دکمهٔ F5).
- **امنیت:** مسیرهای `..` مسدودند؛ بدنهٔ POST تا ۸MB؛ فیلد honeypot در فرم هست.
- اگر صفحهٔ «php-cgi پیدا نشد» دیدید یعنی مرحلهٔ ۱–۳ بالا کامل نشده؛ متن خطا در همان صفحه توضیح داده شده.
