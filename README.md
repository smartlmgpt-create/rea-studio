# REA Studio 2.1.0

A lightweight code editor built with Rust and egui.

### What's New in 2.1.0

- **Tools Menu:** 27 text utilities, including sorting, duplicate removal, case conversion, Base64/URL/JSON conversion, MD5/SHA-1/SHA-256 hashing, EOL/BOM handling, and timestamp insertion.
- **File Comparison:** Side-by-side comparison of two files with navigation between differences using F8.
- **TODO Scanner:** A sidebar tool that scans the entire project folder for TODO/FIXME/XXX/HACK comments.
- **Document Statistics:** Line, word, character, and selection counts, plus an LF/CRLF indicator in the status bar.
- **Cross-Platform Installers:** Setup packages for Windows (NSIS), Linux, and macOS.
